# 串口显示软件开发指南

## 1. 项目概述

本项目是一个基于 Electron + Node.js 的跨平台串口调试助手，支持串口数据的收发、显示、解析和保存等功能。

## 2. 环境准备

### 2.1 开发环境要求

- **Node.js**: >= 18.0.0
- **npm**: >= 9.0.0
- **操作系统**: Windows 10+, macOS 10.15+, Linux

### 2.2 安装依赖

```bash
# 克隆项目后进入目录
cd serial_port

# 安装依赖
npm install

# 如果 serialport 安装失败，可能需要安装编译工具
# Windows: npm install --global windows-build-tools
# macOS: xcode-select --install
```

## 4. 开发流程

### 4.1 启动开发环境

```bash
# 开发模式启动
npm run dev

# 仅启动 Electron（不带热重载）
npm start
```

### 4.2 核心模块开发

#### 串口模块 (src/main/serial.js)

```javascript
const { SerialPort } = require('serialport');

class SerialManager {
  constructor() {
    this.port = null;
    this.isOpen = false;
  }

  // 获取可用串口列表
  async listPorts() {
    return await SerialPort.list();
  }

  // 打开串口
  async open(config) {
    this.port = new SerialPort({
      path: config.path,
      baudRate: config.baudRate,
      dataBits: config.dataBits || 8,
      stopBits: config.stopBits || 1,
      parity: config.parity || 'none'
    });
    // ...
  }
}
```

#### IPC 通信 (src/main/ipc.js)

主进程与渲染进程通过 IPC 通信：

```javascript
// 主进程
ipcMain.handle('serial:list', async () => {
  return await serialManager.listPorts();
});

ipcMain.handle('serial:open', async (event, config) => {
  return await serialManager.open(config);
});

// 渲染进程
const ports = await window.electronAPI.listPorts();
```

## 5. 功能实现指南

### 5.1 基础收发显示

1. 串口连接配置（端口、波特率、数据位等）
2. 接收数据实时显示
3. 发送数据输入框
4. 清空接收区

### 5.2 数据解析

1. HEX/ASCII 显示切换
2. 时间戳显示
3. 数据高亮（可配置关键字）
4. 换行符处理

### 5.3 高级功能

1. **数据保存**: 支持保存为 TXT、CSV、HEX 文件
2. **自动发送**: 定时循环发送数据
3. **多串口**: 同时打开多个串口窗口
4. **图表显示**: 数据可视化（需要解析数值数据）

## 8. 常见问题

### Q1: serialport 安装失败

确保已安装 C++ 编译工具：
- Windows: `npm install --global windows-build-tools`
- macOS: `xcode-select --install`

### Q2: 串口无法打开

1. 检查串口是否被其他程序占用
2. 检查用户是否有串口访问权限（Linux 需要加入 dialout 组）

### Q3: 接收数据乱码

检查波特率配置是否与设备一致。
