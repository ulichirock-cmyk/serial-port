# 串口调试助手详细开发步骤

本文档基于[技术框架](./技术框架.md)和[开发指南](./开发指南.md)，将开发过程拆解为可执行的详细步骤。

## 阶段一：项目初始化与基础架构搭建

### 1.1 项目脚手架初始化
- [ ] 创建项目目录并初始化 `package.json` (`npm init`).
- [ ] 安装核心依赖：
  - `npm install serialport` (串口通信)
  - `npm install --save-dev electron electron-builder` (Electron 框架及打包)
  - `npm install --save-dev electron-rebuild` (用于重新编译原生模块)
- [ ] 配置 `package.json` 中的 `scripts` (`start`, `dev`, `build` 等).

### 1.2 Electron 主进程基础
- [ ] 创建 `src/main/index.js`:
  - 初始化 `BrowserWindow`.
  - 配置 `webPreferences` (启用 `preload`, 禁用 `nodeIntegration`, 启用 `contextIsolation`).
  - 处理应用生命周期 (`ready`, `window-all-closed`, `activate`).
- [ ] 创建 `src/main/preload.js`:
  - 使用 `contextBridge` 暴露 `electronAPI` 接口框架.

### 1.3 渲染进程基础
- [ ] 创建 `src/renderer/index.html`:
  - 搭建基础 HTML 结构 (包含配置区、接收区、发送区、状态栏的占位符).
  - 引入 `styles/main.css`.
  - 引入 `app.js`.
- [ ] 创建 `src/renderer/styles/main.css`:
  - 定义基础布局 (使用 Flexbox 或 Grid).

---

## 阶段二：串口核心功能开发 (后端)

### 2.1 封装 SerialManager 类
- [ ] 创建 `src/main/serial.js`.
- [ ] 实现 `listPorts()` 方法: 调用 `SerialPort.list()`.
- [ ] 实现 `open(config)` 方法:
  - 接收波特率、数据位等参数.
  - 实例化 `SerialPort`.
  - 添加错误监听 (`error` 事件).
  - 添加自动重连机制 (可选).
- [ ] 实现 `close()` 方法.
- [ ] 实现 `write(data)` 方法.

### 2.2 实现 IPC 通信桥接
- [ ] 在 `src/main/ipc.js` 中注册 IPC 监听器:
  - `ipcMain.handle('serial:list', ...)`
  - `ipcMain.handle('serial:open', ...)`
  - `ipcMain.handle('serial:close', ...)`
  - `ipcMain.handle('serial:write', ...)`
- [ ] 在 `src/main/index.js` 中引入并启动 IPC 处理器.
- [ ] 更新 `src/main/preload.js`:
  - 完善 `electronAPI`，将渲染进程的调用转发给 `ipcRenderer.invoke`.

---

## 阶段三：配置与连接功能开发 (前端)

### 3.1 串口配置组件 (SerialConfig)
- [ ] 开发下拉选择框 UI:
  - 端口号 (Port)
  - 波特率 (BaudRate) - 预设 9600, 115200 等.
  - 数据位, 停止位, 校验位.
- [ ] 实现端口列表刷新逻辑:
  - 调用 `window.electronAPI.listPorts()`.
  - 渲染到 `<select>` 元素.
- [ ] 实现"打开/关闭串口"按钮逻辑:
  - 绑定点击事件.
  - 调用 `openPort`/`closePort` API.
  - 根据连接状态切换按钮样式 (红色/绿色).

### 3.2 状态管理与反馈
- [ ] 实现底部状态栏 (StatusBar):
  - 显示当前连接状态 (已连接/未连接).
  - 显示串口参数简报 (e.g., "COM3 | 115200 8-N-1").

---

## 阶段四：数据收发与显示功能

### 4.1 数据接收 (Main -> Renderer)
- [ ] 主进程 `SerialManager`:
  - 监听串口 `data` 事件.
  - 通过 `webContents.send('serial:data', data)` 发送数据到渲染进程.
- [ ] Preload 脚本:
  - 暴露 `onSerialData(callback)` 方法.
- [ ] 渲染进程 `DataDisplay`:
  - 监听数据到达.
  - 实现数据缓存区 (Buffer).
  - **核心功能**: HEX/ASCII 显示模式切换.
    - 实现 `ArrayBuffer` 转 HEX 字符串函数.
    - 实现 `TextDecoder` 转 String 函数.
  - 实现自动滚动 (Auto-scroll) 控制.

### 4.2 数据发送 (Renderer -> Main)
- [ ] 渲染进程 `SendPanel`:
  - 文本输入框 (`<textarea>`).
  - HEX 发送模式复选框.
  - "发送"按钮.
- [ ] 发送逻辑实现:
  - 获取输入内容.
  - 若为 HEX 模式，进行正则校验和格式化.
  - 调用 `window.electronAPI.writePort(data)`.
- [ ] 发送历史记录 (可选).

### 4.3 辅助显示功能
- [ ] 时间戳显示: 在每包数据前添加 `[HH:mm:ss.ms]`.
- [ ] 清空接收区功能.

---

## 阶段五：高级功能与优化

### 5.1 数据解析与工具
- [ ] 实现 `utils/dataParser.js` (渲染进程):
  - 统一处理数据的格式化、高亮、时间戳拼接.
- [ ] 添加定时发送 (循环发送) 功能.

### 5.2 文件操作
- [ ] 主进程 `FileManager`:
  - 实现 `saveFile(content)`: 调用 `dialog.showSaveDialog` 和 `fs.writeFile`.
- [ ] 渲染进程:
  - 添加 "保存接收窗口数据" 按钮.

### 5.3 性能优化
- [ ] 引入虚拟滚动 (Virtual Scroll) 以处理大量数据接收时的页面卡顿.
- [ ] 优化数据刷新频率 (使用 `requestAnimationFrame` 或节流).

---

## 阶段六：打包与测试

### 6.1 功能测试
- [ ] 使用虚拟串口软件 (如 Virtual Serial Port Driver) 模拟收发.
- [ ] 边界测试: 拔掉串口、串口占用、非法数据发送.

### 6.2 构建打包
- [ ] 配置 `electron-builder.json` (图标、应用ID、打包目标).
- [ ] 运行 `npm run build` 生成安装包.
- [ ] 在目标系统 (Win/Mac/Linux) 安装测试.
